# مشروع منصة Soulove SaaS - القواعد والإرشادات الحاكمة (AGENTS.md)

هذا الملف يحتفظ بالقواعد الإلزامية التي يتبعها البوت والـ Agent دائماً أثناء العمل في هذا المشروع.

---

## 🚨 قواعد معمارية وإلزامية صارمة:

1. **العزل التام بين العملاء (Tenant Isolation)**:
   - كل طلب داتابيز، قراءة، تعديل، حذف، رفع وسائط، تسجيل دخول، يجب أن يكون محكوماً بـ `WHERE slug = $1`.
   - يمنع منعاً باتاً خلط الداتا أو التراكم أو مشاركة الجلسات أو الكاش بين العملاء.

2. **التخزين الخفيف ومنع الـ Base64 (Zero Base64 Policy)**:
   - يمنع منعاً باتاً تخزين أو تحويل أو رفع الصور أو الأغاني كـ Base64 داخل PostgreSQL أو داخل كائنات الـ JSON.
   - يتم تخزين الروابط المباشرة الفيزيائية فقط (`https://.../photo.webp`).
   - حجم طلب الحفظ يجب ألا يتجاوز 10KB.

3. **المصدر الوحيد للحقيقة (Source of Truth)**:
   - الـ Seed Data تستخدم مرّة واحدة فقط عند إنشاء الموقع لأول مرة.
   - بعد أول حفظ، الداتابيز PostgreSQL هي المصدر الوحيد للحقيقة، ويُمنع صراحة إعادة حقن الداتا الافتراضية فوق داتا العميل.

4. **سياسة الرفع على Git (Strict Git Push Policy)**:
   - **يُمنع منعاً باتاً رفع أو عمل `git commit` أو `git push` للمشروع إلى GitHub/Git إلا بعد الحصول على إذن صريح وطلب مباشر ومكتوب من المستخدم.**

5. **المصادقة بـ JWT**:
   - جميع عمليات لوحة التحكم والرفع والحفظ محمية بتوكنات JWT آمنة ومُوقّعة معزولة بالـ slug.
