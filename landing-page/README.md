# Soulove Landing Page 🚀💖 (صفحة الهبوط التسويقية والإعلانية)

مشروع مستقل لصفحة هبوط تسويقية مخصصة لحملات الإعلانات (Facebook Ads / TikTok Ads / Google Ads) لتحقيق أعلى معدل تحويل (High Conversion).

---

## 🌟 المميزات:
1. **Hero Section جذاب ومؤثر**: مع أزرار CTA واضحة وتحفيزية.
2. **شاشة محاكاة هاتف تفاعلية (Phone Preview)**: لتجربة الموقع والمشغل والأمنيات والـ QR بشكل حي.
3. **شبكة مميزات حصرية (Features Grid)**: تشرح كل ميزة وتأثيرها العاطفي.
4. **شرح في 3 خطوات بسيطة (Steps)**.
5. **جدول باقات وأسعار احترافي (Pricing Table)** مع خصومات محفزة.
6. **آراء وتقييمات العملاء الموثقة (Reviews & Social Proof)**.
7. **الأسئلة الشائعة (FAQ Accordion)**.
8. **نموذج طلب سريع وتوجيه فوري للواتساب (Order Modal)** لجمع بيانات العملاء وبدء المحادثة برسالة جاهزة.
9. **زر واتساب عائم نابض (Floating WhatsApp Button)**.
10. **أماكن جاهزة لبكسل الإعلانات (Meta Pixel & TikTok Pixel)** في `index.html`.

---

## 🛠️ كيفية التشغيل محلياً:

```bash
cd landing-page
npm install
npm run dev
```

---

## 🚀 كيفية الرفع على Vercel:

1. افتح حسابك في [Vercel](https://vercel.com).
2. اضغط **Add New > Project**.
3. اختر مستودع المشروع (Repository) وحدد **Root Directory** ليكون `landing-page`.
4. اضغط **Deploy** وسيتم نشر صفحة الهبوط فوراً برابط مستقل أو ربطها بدومين مخصص!
